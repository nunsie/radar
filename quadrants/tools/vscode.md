Capable and ubiquitous, with an unmatched extension surface, but it is heavier, slower to start, and increasingly a hub for metered AI features I do not want to manage per-editor. Hold for new work: keep it only where a specific extension or a team standard still requires it.

Revisit if it gets meaningfully leaner, or if a needed extension has no equivalent in my default editor. The switching cost is real and specific, so name it before paying it.
