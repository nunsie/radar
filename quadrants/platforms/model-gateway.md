A gateway in front of models — OpenRouter and similar — giving one API across frontier and open models, with cheap and free options that make agentic work affordable to run all day, plus routing and fallbacks. It keeps model choice a config decision instead of a rewrite.

Trial: ideal for experiments and choosing a model per task, but keep a direct provider path for anything important so the gateway stays a convenience rather than a single point of failure.
