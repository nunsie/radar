One position for the agent CLI in my terminal: Pi is the default, with Claude Code, OpenCode and GitHub Copilot as alternatives depending on provider and limits. What matters is the shape — a small, hackable agent that runs the model against real tools (read, edit, bash) with the session and the diff in front of me — not which vendor ships it.

Trial: useful enough to reach for on anything where I keep the design and review the output, and still young enough that I do not hand it the controls. This is the fastest-aging cluster on the radar; expect the names to rotate, so hold the position, not the brand.
